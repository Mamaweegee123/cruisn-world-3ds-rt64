# Known issues and limits

- RT64 adapter is not connected to the authentic game task path.
- Authentic task dependencies, memory ownership/synchronization, microcode identity, side-effect replacement, and perspective normalization remain unresolved.
- The synthetic host fixture is not evidence of game rendering.
- No visible gameplay, menu, controls, or race has been verified.
- No original 3DS hardware validation.
- Exact source-to-binary lineage for the historical runtime baseline is incomplete.
- External RT64-3DS dependency source and license are not included/verified here.
