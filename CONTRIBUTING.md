# Contributing

Keep this feasibility adapter separate from the ARM11 software-RDP effort. Do not describe the renderer as connected until an authentic game task reaches a visible frame. Preserve synthetic-test limitations in any report.

Do not add ROMs, generated game code, runtime binaries, saves, or extracted assets. Before running tests, obtain the referenced RT64-3DS source at the documented revision and verify its license. This candidate has not been built or tested as part of its preparation.
